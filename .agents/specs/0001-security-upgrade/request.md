## 앞선 요청 (같은 대화)

이거는 그거야 프로젝트 규모에 따라서 달라져 프로젝트가 작은데 온톨로지랑 prd sdd 를 사용하면 생산성이 떨어지지 그런데 프로젝트가 커진다면 여러개의 서브에이전트들이 같은 내용과 규칙으로 움직이여야 한다면 온톨로지가 필요해 이건 실제로 실험을 해본거니까 작은 프로젝트이거나 중간 규모의 프로젝트면 온톨로지가 없어도 되고 차라리 온톨로지를 넣을거면  prd 를 빼고 sdd 를 넣는거지 그렇게 되면 엔티티도 필요할거고 하네스 랩에서 실험결과가 의미가 있을수도 있지만 지금은 하네스랩에서 조금더 한단계 위에 실험을 하는거라서 하네스에서 사용한 에이전트 디자인을 가져가고 거기에데가 보안을 검증하고 미리 막을수 있는가 이거를 테스트 해보고 싶은거야
