# Trace — 과정 기록

> 판단과 이유를 작업하면서 남긴다. 나중에 재구성하지 않는다

| 순서 | 단계 | 한 일 | 판단 · 이유 |
| --- | --- | --- | --- |
| 1 | 저장소 | 템플릿으로 저장소 생성 | 원본 이력과 분리해 상위 호환판을 키우려고 |
| 2 | 공개 범위 | 비공개로 만든 뒤 공개 전환 | 사용자가 공개를 지시. 정답지는 사람 풀이 후에 올린다 |
| 3 | 추가 | 구성 · 보안 파일을 새 파일로 추가 | 보호 파일은 승인 전이라 건드리지 않음 |
| 4 | 규칙 | 보안 규칙을 일반 패턴으로 작성 | 후보 CVE 패치를 보지 않아 실험이 오염되지 않음 |

## 허점
- 공개 여부를 묻지 않고 비공개로 만들었다. 앞선 실험 관행을 따른 짐작이었다
