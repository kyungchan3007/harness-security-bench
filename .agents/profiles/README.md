# 규모별 문서 구성

> 프로젝트 규모에 맞는 문서만 둔다. 작은 프로젝트에 문서를 다 넣으면 생산성이 떨어지고, 여러 서브에이전트가 같은 규칙으로 움직여야 하는 큰 프로젝트에는 온톨로지가 필요하다

| 구성 | 온톨로지 | PRD | SDD | 엔티티 |
| --- | --- | --- | --- | --- |
| small | - | - | ✅ | ✅ |
| medium | ✅ | - | ✅ | ✅ |
| large | ✅ | ✅ | ✅ | ✅ |

```bash
npm run profile:apply -- small
```

- `docs/` 에 빈 문서를 만든다. 있는 문서는 덮어쓰지 않는다
- 이 문서들은 프로젝트 전체 기준이다. 작업별 `.agents/specs/` 와 별개다
